# Tengri Kezgen Köçer

Göç, Yerleşim & Yaşam Rehberi — [tengrikezgenkocer.com](https://tengrikezgenkocer.com/)

## Proje Hakkında

Tengri Kezgen Köçer, göç eden bireylere ve ailelere kapsamlı rehberlik hizmeti sunan bir web platformudur. Vize danışmanlığı, konut & yerleşim, eğitim rehberliği, mali planlama, sağlık sistemi ve kültürel uyum konularında bilgi ve destek sağlar.

## Özellikler

- Modern ve responsive tasarım (mobil, tablet, masaüstü uyumlu)
- SEO ve erişilebilirlik optimizasyonları
- Animasyonlu sayaçlar ve scroll efektleri
- İletişim formu
- Hizmetler, rehberler ve deneyimler bölümleri
- Performans odaklı (saf HTML/CSS/JS, framework bağımlılığı yok)

## Dosya Yapısı

```
├── index.html          # Ana sayfa
├── css/
│   └── style.css       # Stil dosyası
├── js/
│   └── main.js         # JavaScript (menü, animasyonlar, form)
└── README.md
```

## Geliştirme

Herhangi bir build aracına ihtiyaç yoktur. Dosyaları doğrudan bir web sunucusuna yükleyerek kullanabilirsiniz.

```bash
# Yerel geliştirme için basit bir HTTP sunucusu başlatın:
npx serve .
# veya
python3 -m http.server 8000
```
